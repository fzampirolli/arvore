    Sobre este site

    Como contribuir

    As páginas são geradas automaticamente a partir de uma estrutura de pastas — cada pasta é uma pessoa:

    04Magri/                      ← um sobrenome (família)
└── 00Giuseppe/               ← uma pessoa
    ├── DADOS.TXT             ← dados pessoais
    ├── HISTORIA.TXT          ← (opcional) história, em texto livre
    ├── fig/                  ← (opcional) fotos; subpastas viram álbuns
    │   └── Casamento_de_Rosa_1910.jpg
    ├── certidao_de_casamento.pdf   ← (opcional) documentos
    └── 01Carlos/             ← um filho: 2 dígitos (ordem de nascimento) + nome
    1. Para cada filho, crie uma subpasta com dois dígitos de ordem de nascimento e o nome, trocando espaços por _ (ex.: 11Francisco_de_Assis). Use 00 se a ordem for desconhecida.
    2. Crie o arquivo DADOS.TXT, uma informação por linha: 
      Nascimento: 06-12-1968, Jaciguá, Cachoeiro de Itapemirim - ES
Esposa: Nome Completo (nascida em 15-01-1970, Rio de Janeiro)
Casamento: 19-12-1998, Niterói - RJ
Falecimento: 02-03-2001, Vitória - ES
Nome do navio: Adria
Data de chegada: 31/12/1888
Ultima residência: Pettorazza Grimani
      Também são aceitos Esposo, Marido, Telefone, Endereço — telefone e endereço nunca são publicados na versão pública.
    3. Coloque as fotos na subpasta fig, com nomes descritivos (Bodas_de_Ouro_2000.jpg). O nome vira a legenda.
    4. Rode python3 gerador/gerar.py na pasta principal. O site fica em site/.

    Não precisa saber programar: envie as pastas compactadas (.zip) ou as informações por e-mail para quem mantém o site.

    Privacidade

    Na versão pública, pessoas que podem estar vivas (nascidas há menos de 100 anos, ou sem data mas de gerações recentes) aparecem apenas com o ano das datas, sem horários, endereços, telefones ou e-mails. Se você quer que seus dados sejam retirados ou corrigidos, entre em contato.

    Arquivo GEDCOM

    O arquivo arvore.ged (padrão GEDCOM 5.5.1) pode ser importado em FamilySearch, MyHeritage, Ancestry, Gramps e outros programas de genealogia.

    História do projeto (texto original, 2001)

    A idéia de criar árvores genealógicas na Internet foi do meu irmão Fernando Zampirolli ([e-mail omitido]) e eu, numa visita que o fiz em Belo Horizonte em 1996. Passados alguns anos, com a chegada das bodas de ouro dos meus pais, voltou o interesse em melhorar as páginas localizadas inicialmente em Árvore Genealógica da família Zampirolli. Para isto, criei um gerador automático de páginas. Este gerador só funciona se os dados estiverem estruturados da forma abaixo. Para que este trabalho seja de boa qualidade, conto com a ajuda de todos para fazer um levantamento de toda informação relevante de nossas famílias. Por favor, divulgue ao máximo esta página. Dicas para geração automática de páginas html: (0) Se quiser criar um novo ramo de sobrenomes, crie um diretório sobrenome. Observe que já esta criado para Zampirolli, Balarini, Dalfiôr e Magri. Não é necessário criar novamente para este sobrenomes. Para cada diretório correspondente a uma pessoa faça: (1) Crie um subdiretório para cada filho, se existir. Os espaços serão substituídos por '_'. Além disso, coloque dois números de 0 a 9 antes do nome para a ordem de idade dos filhos. Por exemplo, 'Francisco de Assis' deverá ter o diretório chamado '11Francisco_de_Assis'. (2) Crie um arquivo chamado 'dados.txt' contendo, por exemplo: Nascimento: __-__-1___, às __ hs, local Esposa: __________________ (__-__-1___, às __ hs, local_____) Data, Hora e Local do casamento: __-__-1__,_ às __hs, local____ Telefone: (0xx__) ____ ____ Endereço: ________________________________________________ ... (3) Crie um subdiretório chamado 'fig' com as fotos que serão postas nas páginas. Use nomes sugestivos para as fotos, por exemplo: 'Aniversáro_do_Vinícios_12-12-2000.gif'. Observe que em vez de espaço, coloquei '_'. De preferência use o formato 'gif' para as imagens, pois é bem compacto. (4) Crie um arquivo chamado 'historia.txt' contendo o que achar relevante sobre a sua vida, familia, profissão, etc. (5) Criados os diretórios, arquivos .txt e fotos, as páginas são geradas automaticamente através de um programa chamado "fzgenHtlmFamily.m" que só é executado na linguagem MATLAB. Creio que este passo (5) seja inviável para quem não conhece esta linguagem Matlab. Logo, me disponho a gerar as páginas Html. Para isto, basta enviar a estrutura de diretórios, comprimidas com um compactar que gera .zip, por e-mail. Lembre-se que estes documentos estarão disponíveis na Internet, logo não coloque dados importantes sobre a sua pessoa, como por exemplo, número de documentos. Em breve, irei criar um programa que gera arquivo 'poscript'. Com isto, poderemos imprimir, em forma de livro, as árvores genealógicas. Quaisquer dúvidas, sugestões e/ou informações, escreva para: [e-mail omitido] ou [endereço omitido] [endereço omitido] [endereço omitido] Francisco de Assis Zampirolli.
